# Recipe template

1. Title and one sentence of what it is for, with machine (chip, cores, RAM, macOS).
2. Changes from the base recipe, as a table with every changed setting, including window mode and graphics backend.
3. Download links and exact versions. Nothing redistributed.
4. Measurements. State resolution, window mode, cap, which flight of how many per launch, the baseline column label with its window mode, and the other flights. State the noise.
5. Portrait, and say it came from a separate windowed launch.
6. What it costs and what was tried (one table).
7. Limits, including any gameplay checks not done.
8. Rollback.
