# Community experiments

Reviewed data-only submissions appear here as `<content_digest>.json`. Use `silicon-shader challenge prepare`, inspect the bundle, then opt in with `challenge submit`. Entries contain a public GitHub handle and validated bundle. They remain **self-reported** after review; merging does not certify independent reproduction.

Maintainers must verify the author matches the submitting GitHub account, inspect recipe reproducibility and quality claims, and review the exact data before merging. The automated gate validates with the base branch's code and never executes contributor code. Changes to the validator belong in a separate code PR. See [the rules](../docs/CHALLENGE.md).
