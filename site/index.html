 A BETTER IMAGE NEEDS BETTER EVIDENCE

How progress works

  1. Pair the experiment. Baseline and candidate on the same machine, route, scene and output resolution. Declare every changed setting.
  2. Keep gameplay real. Use short, living-player routes. Reject menus, death screens, black worlds, focus loss and incomplete captures.
  3. Check the image. Human review records equivalent quality, an improvement, or a visible tradeoff. FPS cannot judge image quality.
  4. Make it inspectable. Public recipes and relative frame intervals let others recompute the metrics and repeat the experiment.
  5. Keep claims precise. Automated validation checks trace consistency. It does not prove physical hardware, visual quality or independent reproduction.

These are CPU frame-production timings, not displayed, generated or GPU-presented FPS. A short capture does not qualify a complete daily setup.
