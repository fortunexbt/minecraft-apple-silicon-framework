Prefer the manual CLI?

Requires Python 3.10+ and Minecraft Java. Use a Python environment to avoid changing your system packages.

git clone https://github.com/fortunexbt/minecraft-apple-silicon-framework.git
cd minecraft-apple-silicon-framework
python3 -m venv .venv
. .venv/bin/activate
python -m pip install .

A QUICK WAY TO USE THE LIBRARY

Check the recipe first.

FPS depends on the Mac, shader, scene, resolution and settings. Read the recipe and evidence before comparing two cards.

  1. Filter by your chip family, tier and memory.
  2. Compare output and internal resolution, shader settings, view distance and the test scene.
  3. Ask your agent to check compatibility and prepare an isolated copy before trying a change.

The library shows contributor-submitted captures. An image-quality review is not an independent performance reproduction.
